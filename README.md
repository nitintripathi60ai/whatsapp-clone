# WhatsApp Clone - Angular + Socket.io Real-time

## Run
```
# Backend
cd backend
npm install
npm start
# Port 3000

# Frontend
cd frontend
ng serve
# localhost:4200
```

## Features
- Real-time chat (global room)
- Responsive UI
- WhatsApp design
- Mobile friendly

## Test
